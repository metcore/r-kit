# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Sebelum mulai kerja di repo ini, baca [.claude/MEMORY.md](.claude/MEMORY.md)
— index catatan project (konvensi, keputusan, hal non-obvious) yang perlu
diketahui sebelum ngoding di sini.

Sebelum bikin/ubah komponen di sini, baca
[.claude/skills/syncing-component-touchpoints/SKILL.md](.claude/skills/syncing-component-touchpoints/SKILL.md)
— checklist doc/playground/landing yang wajib disinkronkan tiap ada
perubahan komponen.

Skill portabel (superpowers, hallmark, caveman, dll) ada di
[.claude/skills/](.claude/skills/) — otomatis kedeteksi Claude Code, di
device manapun begitu repo ini di-clone, tanpa perlu install plugin apa pun.
