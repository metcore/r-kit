## Impor

```tsx
import { useInputGroupControl } from '@herca/r-kit/clients';
```

## Penggunaan

```tsx
const control = useInputGroupControl();
```

## Kembalian

| Nama | Tipe | Keterangan |
| --- | --- | --- |
| `control` | `konteks kontrol` | Keadaan isian di dalam kelompok |

## Catatan

Pasangan dari `useInputGroup`, untuk bagian isiannya.
