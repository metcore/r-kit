## Impor

```tsx
import { useSheetHref } from '@herca/r-kit/clients';
```

## Penggunaan

```tsx
const href = useSheetHref();
```

## Kembalian

| Nama | Tipe | Keterangan |
| --- | --- | --- |
| `href` | `string` | Alamat yang menyertakan keadaan sheet |

## Catatan

Pasangan `useTabHref`, untuk komponen `Sheet`.
